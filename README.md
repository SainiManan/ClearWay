# SafeStride 🌙

A safety-aware walking route recommendation prototype.

## Features
- Starting point and destination inputs
- Route comparison interface
- Planned safety indicator scoring
- Planned interactive map

## Setup

Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

Run the application:

```powershell
streamlit run app.py
```
